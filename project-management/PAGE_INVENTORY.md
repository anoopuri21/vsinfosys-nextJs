## Workflow applied to every page

1. Plan sections, search intent and visual story.
2. Design the page using the shared cinematic system.
3. Write and validate original SEO-focused content.
4. Build and verify semantic HTML, custom CSS, responsive behavior and architecture.
5. Mark complete and select the next page.
